把皮肤包丢进这个文件夹，下次启动会自动装好。

步骤：
1. 从 Release 下载 with-me-skin-*.zip（大肥鱼皮肤是单独的一个文件）；
2. 原样放进这里，不要解压；
3. 双击 run.cmd 或 启动.vbs。

装好之后，这里对应的 zip 会被删掉（内容已经在 userdata\skins\<皮肤 id>\）。
装错了就删掉 userdata\skins\<皮肤 id>\，重新放一个 zip 再启动。

说明：
- 这个文件夹里的 zip 不进 git，也不进源码包。
- 大肥鱼皮肤是 CC BY-NC-SA 4.0，禁止商用；许可全文在包内的 LICENSE-CC-BY-NC-SA.txt。
- 源码包里只有内置的 block（色块）占位皮肤。
