# with-me · Windows 桌面宠物

一只站在桌面上的宠物：自己按规则和权重播动画，点一下出按钮面板，点按钮换动作，
其余区域鼠标完全穿过它落到下面的窗口。角色可以整个换掉——换一只宠物等于换一个目录。

当前状态：v1 开发中，Windows 首发。macOS 只在平台层留了接口形状，没实现。

---

## 怎么跑起来

```bash
npm install          # 依赖走 npmmirror 镜像，见 .npmrc
npm run skin:test    # 生成占位皮肤（色块）的动画，不需要美术素材
npm start            # 构建并启动
```

`npm start` 之后桌面上会出现一个绿色色块。它没有美术素材是故意的——
v1 先证明架构成立，角色形象另说（见「文档」一节）。

常用命令：

| 命令 | 做什么 |
|---|---|
| `npm run typecheck` | TypeScript 检查，不产出文件 |
| `npm test` | 纯逻辑单测（条数以这条命令自己的输出为准，别信文档里的快照） |
| `npm run build` | `tsc` + 复制 html/css/svg/png/woff2/mp3/json 与 preload。没有打包器 |
| `npm run e2e` | 真 Electron 上验播放器、面板、气泡、列表、光标、心跳、可见性子进程 |
| `npm run e2e:skin` | 真 Electron 上验「换皮肤」这条轴 |
| `npm run alpha:check` | 素材透明通道体检 |
| `npm run dist` | 出安装包与免压 zip（见「发布流程」；产物在 `release/`，不是 `dist/`） |
| `npm run check:license` | 许可闸门：素材有没有登记、形象素材有没有混进包 |
| `npm run skin:pack` | 装配大肥鱼皮肤包 zip（素材不进 git，只能在本地出） |
| `npm run progress` | 重新生成 `docs/实现进度.md` |

## 怎么用起来

- **面板怎么叫出来**：**点一下宠物**才出，鼠标路过或停上去都不弹（以前是停留 400ms 自动弹，
  整屏覆盖层上那个太容易误触，2026-11-04 改掉）。再点一次收起；离开身体与面板满 1500 毫秒也自己收。
  面板默认从脚底下递出来（脚下挨着屏幕边就翻到头顶），横向以**角色的对称轴**居中，不是贴着身体左沿。
  移开宠物的一瞬间鼠标就还给桌面了，不必等面板收。
- **面板是两块，不是一块**：根节点 `.pet-panel` 铺满覆盖层、不吃命中，只当 `data-hit` 的宿主；
  里面 `.pet-actions` 按钮条 + `.pet-plate` 副板各自 `transform` 定位。
  点喂食/状态时**按钮条不消失**，副板另找自己的位置：食物列表挂在按钮条**外侧**
  （按钮在脚下时往下长、翻到头顶时往上长，中间那段永远留给宠物），
  状态读数挂在**宠物右侧**。合成一块做不到——三个锚点不共边，而外接矩形会把中间一大片
  看不见的地方圈成命中区，桌面就点不动了。**设置已经搬到系统托盘**（2026-11-12）：面板里不再有设置页，
  托盘菜单负责显示/隐藏、静音、全屏时隐藏、开发者模式、皮肤切换和退出。再点一次同一个视图按钮 = 收回副板。
- **面板的出场动画只给按钮条**：四颗**从左到右依次弹出**，每颗比前一颗晚 55ms（档位 `--i` = 从左数第几颗，
  `panel.ts` 按按钮数量算好写进 style），收尾用带过冲的 `cubic-bezier(.34,1.56,.64,1)`——
  等价于 GSAP 的 `stagger: .055` + `back.out(1.7)`，但**没有引 GSAP**：它值钱的地方是时间线编排、
  滚动触发、物理缓动，这里只要一次性入场错落，CSS 变量就够（这仓库的规矩是无框架、手写 CSS 变量）。
  每颗沿「离宠物那一侧」浮 6px 归位，方向读根节点的 `data-side`（脚下 +6px、头顶 -6px）；
  单颗 0.22s、最后一颗 440ms 落定，和气泡淡入同一族。
  **副板（食物列表 / 游戏列表 / 状态读数 / 调试板）直接出现，不做任何动画**——2026-11-06 用户拍的板；
  以前给它配过 scale + translate + `transform-origin` 那套，274px 的卡片胀开再落定，读起来像整块板在抖。
  三条硬约束：
  ① **只用独立的 `scale` / `translate` 属性，不碰 `transform`**——那是 `place()` 每帧写的定位，
  按钮悬停也占着它，独立属性会和 `transform` 自动相乘，所以互不打扰；
  ② 只在「从 `display:none` 出来」那一次跑（`@starting-style`），前提是 **`render()` 跨视图复用按钮条**——
  节点要是每次换视图都重建，数值快照每 60 秒推一次就会把四颗重新弹一遍；
  ③ 收起只做淡出、不做反向缩回。
  关掉动画有两条出口，都是把 `.pet-panel` 上那四个旋钮拧回中性值：系统的 `prefers-reduced-motion`，
  以及 `data-no-motion`（e2e 开局就挂上它——几何断言不该和 200ms 的位移赛跑）。
  **和 qqpet 对照过**（`demo-project/qqpet/src/renderer/ui/control.ts:191-197`）：它的错峰是 JS 递归
  `setTimeout(…, 150)` 切一个类、把图标从 30px **跳**到 40px，没有缓动、没有插值，收起也没有对应动作；
  容器出现/消失本身连 transition 都没有。所以我们这套（scale + back.out + 方向位移）比它强，不照抄。
  从它那里值得拿的是**不对称的收起延时**（子菜单收起时 `opacity .2s .3s, visibility 0s .5s`、
  出现时立刻可见，为的是光标斜着移过去时中间那段还吃得到点击，`control.css:132-146`）——
  这条我们还没有，是「面板开着时移向食物格」那条路径上值得补的一课。
- **按钮**：四个图标——米饭（喂食）/ 手柄（小游戏）/ 爱心（状态）/ 调试图标（调试），
  **调试那颗默认藏掉**（2026-11-11）：在托盘菜单里开了「开发者模式」才露面（`panel.ts` 的 `syncDebugGate` 翻 `hidden`）。
  每颗底下垫一枚 Kenney UI Pack 的 `button_round_depth_line`（CC0，**已按 A 套「品牌蓝白」重染**：
  面 `#EBF5FB` + 环 `#6990A7` + 下半圈更深的底影 `#3E718C` + 那条青内圈 `#36BDF7` 原样没动），
  图标叠在圆底上面。素材原色是中性偏紫的灰（面 `#DADCE7` L=89.6），透在桌面上看着就发暗；
  重染的推导在 `spike/color-math.mjs`、执行在 `spike/palette-recolor.mjs`，
  色值与「旧灰紫绝迹」由 `test/palette.test.ts` 钉住——重装素材会把原色盖回来，而功能测试不会变红。
  2026-11-06 批次二曾把它换成**手绘小鲸鱼**（形状 + 素材内描边当边框），用户在真机上看过一句
  「现在的不好看」，当天改回圆底：鲸鱼素材与 `spike/whale-button.mjs` 一起删掉，
  形状要再试从提交 `0d60c3e` 取回来（见 problem/05 §5.28）。
  **投影留下了**（`filter: drop-shadow(0 2px 2px rgba(0,0,0,.32))`）——那是「更立体」那条独立要求，
  跟形状无关；它跟着 alpha 轮廓走，圆底出来是一圈落在桌面上的软影，比素材里那道底影更像「浮着」。
  命中区是 40 见方，**图标尺寸逐枚定**（20 / 24 / 24 / 22）——这四张图的内部留白各不相同，
  一刀切 26px 时碗的筷子和调试图的腿会戳出圆底青圈（青圈内半径 15.6px，26px 方框的墨迹半对角 18.4px），
  爱心和手柄又空出一大圈。数值由 `spike/icon-metrics.mjs` 量墨迹实迹反推，e2e 钉住这张表。
  悬停时**整颗一起**放大 1.15（只放大图标会戳出圆底外沿）。
  圆底只挂在动作按钮（带 `data-id`）上——列表、状态、调试视图里的按钮各有自己的方形底板，叠两层会像画歪了。
  **圆底没有视觉选中态，这是拍板不是遗漏**：`.on` 仍然挂在当前视图那颗上（状态语义与测试靠它），
  但不画任何东西——试过一圈 `outline` 描边环，用户看后说「不要出现外面的一个黑圈」。
  也**绝不能用卡片的 `background` 简写去表意**：简写会把圆底那张图擦成 `none`，
  按钮当场露成 40×40 的正方形（真发生过，见 problem/05 §5.17）。
  图标是 `src/renderer/icons/` 里的 SVG 加 `src/renderer/emotes/` 的 PNG，文字退成 `title` 与 `aria-label`。
  喂食/小游戏/状态/调试都是切视图（食物列表、游戏列表、状态栏、调试板各自一块）；调试板见下条。
  食物列表是底板 + 方形按钮：那是文字行，浮在桌面上读不成句。

  UI 和食物列表**一模一样**：左右翻页键 + 4 格宽视口（204px）+ 一排方形格子（`GAME_CELL`/`GAME_ICON`/`GAME_GAP` 与食物同量级，
  由 `test/config.test.ts` 反查钉住）+ 底部拖拽条（溢出才出现）。格子里是**生成的生动图标**（`icons/game-{fly,guess,bubble}.png`，
  ImageGen 出图 → `tools/make-game-icons.mjs` 抹水印缩到 128×128）：鲸鱼被抛上天 / 鲸鱼挥手顶问号 / 手指戳破泡泡。
  名字退成 title/aria-label，点一格 = 开那个游戏。现在 3 个游戏装得下，翻页键置灰、拖拽条不画（和食物列表装得下时一致）；
  游戏多了溢出时拖拽条自然出现（滚动状态与食物同构，走同一套 `shared/scroll.ts`）。
  进游戏态后**脚下按钮条收掉、这段时间不弹聊天气泡**（`openPanel` 与 `say` 都被 `activeGame()` 闸门挡住），
  退出走浮层上的退出键（`stop()`），收回普通态。三个游戏共用同一套游戏态接口 `{active,start,stop,hudRect}`，
  装配层用 `activeGame()` 判「现在有没有游戏在跑」，同一时刻只会有一个。
- **「鲸鲸会飞」小游戏**（2026-11-07 从 spike 转正式）：抓住宠物往上抛，看它飞多高。
  纯物理在 `src/shared/game.ts`（`throwVelocity` 卡 MIN/上限、`stepFlight` 只管向上初速与下落封顶，向上的速度归零后回落）。
  **宠物能整块飞出屏幕上沿且继续计数**——这靠 `motion` 新开的 `setPositionUnclamped`：普通拖拽仍走夹取的 `setPosition`
  （免得被丢出屏幕找不回），两者意图相反、各用一个口子。游戏活在**命中框(hitBox)坐标系**里（抓住的是看得见的身子），
  `index.ts` 的 `setPos` 负责换算回舞台坐标。游戏态下常规拖拽/点击在 `game.active()` 时全部让路。节拍走 `setInterval(~33ms)`
  + 真实 dt，不用 rAF（这扇覆盖层对 rAF 节流有前科）。HUD 在屏幕顶部居中（深色底，`.pet-fly-hud`：高度 / 最高 / 速度 + 退出键），
  交互区把它的矩形也并进去，才不会一路闪回桌面光标。e2e 用 `hitBox.y + h < 0` 钉死「真的抛出屏外」——以前只抛 ~66px
  的检查被夹取掩护过、给了假绿。
  **屏外快落**（用户 2026-11-08 嫌「等它掉回屏幕太久」）：宠物整块还在屏幕顶外**且正在下落**时，用更大的重力 `G_OFF`
  + 更高的下落上限 `FALL_CAP_OFF` 赶紧回到视野；一露进屏幕就切回 `G`/`FALL_CAP` 轻柔落地。只在下降段提速——上升段仍用正常 `G`，
  否则屏外甩上去会被大重力提前刹住、顶点高度就不一致了（`test/game.test.ts` 钉着）。
  **高度怎么来的（动能 + 质量模型，用户 2026-11-08 拍板）**：松手前 ~90ms 的鼠标位移算出甩速 `v_hand`，
  这一甩当成给宠物一份**固定能量**（做功），而不是固定速度——`E = ½·M_REF·(v_hand·POWER)²`，
  再喂给质量为 `m = 体重读数` 的宠物：`v_launch = v_hand·POWER·√(M_REF/m)`。
  **高度量的是「这一抛离松手点飞出去多高」**：`最高 = (松手点 − 最高点)/PX_PER_M = v_launch²/(2·G) = E/(m·G)`，
  不是离地总高度。为什么——以前按地面算，把宠物拖到屏幕顶再甩，光「松手点已经很高」就白送十几米，
  再叠上顶到上限的抛体段，成绩就顶成一个常数（用户看到的「一碰顶就 180」）。改成按松手点算后，拖拽抬升不计，
  数字只反映甩得多猛。
  **为什么绕能量这一圈**：若直接测速度再用 `h=v²/2g`，质量会在 `½mv²=mgh` 里**约掉**，胖瘦抛一样高、体重白设；
  只有把输入定成能量，`h ∝ 1/m` 才成立——越重飞得越低。`M_REF=50`（= 初始体重）标定：体重 50 时手感就是下面这套数字，
  更轻飞更高、更重飞更低；`M_MIN=5` 兜底别让 `√(M_REF/m)` 炸开（`THROW_CAP` 也再夹一层）。
  参数都在 `shared/game.ts` 的 `FLY`：`G=800`、`POWER=0.6`、`THROW_CAP=3200`（早先 1600 太低，快甩全顶格 →
  高度全钉死在 ~70–85m「怎么甩都一个数」，抬到 3200 后慢/中/快约 20/60/150m 能拉开；上限暂不再动）。
  落地那一下 `readout` 把高度夹在 ≥0，不再闪出「-1」。`test/game.test.ts` 钉了三条：越快越高、同速下越重越低（√(M_REF/m)）、
  以及「同一初速从地面和从半空松手，最高一样」——最后这条就是钉住「拖拽抬升不计分」。
- **「猜动作」小游戏**（2026-11-08，参考 qqpet 同名游戏的玩法、不搬它的代码）：**一局固定 10 道题**（`GUESS_QUESTIONS`），
  每局从库里抽 10 个**互不重复**的目标逐个问；每题宠物做一个动作、浮层出 3 个动作按钮，点「它刚做的是哪个」。
  记分行进行中显示「第 m/10题 · 正确 n/10」，答完第 10 题改成「本局答对 n/10」并自动结算。点对计分、进下一题；
  点错不加分，但会把正确那颗亮绿告诉你答案。
  **动作库 20 条**（`GUESS_ACTIONS`，`shared/guess.ts`），分 5 类、**不含「吃东西」**（那口归喂食列表）：互动反应 4 /
  特效与展示 4 / 舞蹈与音乐 5 / 节日与节气 4 / 玩耍 3。其中 12 个是用户点名的目标，另 8 个是**同分类**里挑来当错误答案的干扰项——
  每类都 ≥3 条，所以任何目标都凑得出 2 个同类兄弟。纯逻辑 `pickTargets(rng, 10)` 把整库洗一遍取前 10 个当本局目标（洗牌+切片天然不重复）；
  `buildRound(target, rng)` 每题在同分类其余动作里取 `GUESS_OPTIONS-1` 个当干扰、再把「目标+干扰」洗一次顺序（目标一定在选项里、不总在第一颗），`test/guess.test.ts` 钉着。
  这 20 条 clip 都在皮肤的 **`guess` 池**（`animation/guess/<ascii名>.webm`，切自 dsh-pet 原片、只落 %TEMP%，见 `spike/dsh-asar-extract.mjs`，
  且**不计进 bodyBox**——不然放烟花那种张开的大框会把全局锚点撑歪）。渲染层**按名寻址**播（`requestClip('guess', name)`，不是随机池里挑一条），
  所以只有装了这些原片的试穿皮肤才真演；换 block 占位皮肤这些 clip 不在、点了不动（游戏 UI 与计分照常）。
  每题目标动作先播一遍；若这条**真播完**了还没人答，行为链在 `ended` 那一拍按 `guessGame.loopRef()` **无缝续挂同一条**，
  直到答为止——不进 idle、也不把正在播的动画从头切断（用户 2026-11-08 要「播完直接重复、不要 idle 那一下」）。
  早先试过渲染层挂 2.4s 定时器重播：比 10s 片长短太多会切进播放中重启；后改 10.6s 定时器又会在片尾掉回 idle 一小下。
  最终用链子既有的后台槽预热续挂（和 idle/turn 的 loop 同一条路），接缝看不出。渲染控制器 `renderer/guess.ts` 和飞同一套接口，但**不接管拖拽**。
  退出/答完按**这一局答对数**结算（见下条），答对越多给越多。
- **「点泡泡」小游戏**（2026-11-08）：限时 **30 秒**（`BUBBLE_GAME_SECONDS`），泡泡从屏幕底部不断冒出往上飘（带左右晃），
  点中一个就破（**原地**放大淡出 ~180ms）、计数 +1，飘出顶的算 missed；时间到自动结算，也可提前点退出键。
  **难度曲线**：前 `BUBBLE_CALM_SECONDS`=3 秒匀速让用户上手，之后上浮速度按 `bubbleSpeedFactor(elapsed)` 线性爬升
  （`BUBBLE_RAMP_RATE`=0.1，每秒 +10%，30s 时约 3.7 倍），作用于场上所有泡泡（`test/bubble.test.ts` 钉着）。
  泡泡是**内嵌 SVG 正圆**（+ 左上高光，只变大小/色相/速度，形状都是正圆），不用图片素材；纯参数 `makeBubble(rng, W, lane, lanes)` 在
  `shared/bubble.ts`（`test/bubble.test.ts` 钉着）。**横向按车道铺匀**（用户 2026-11-08 要「左右均匀」）：把屏宽分成 `BUBBLE_LANES`=5 条，
  控制器每冒一个就轮转 `lane`（0→1→…→4→0），泡泡只落在自己那段里随机取 x，不会纯随机挤到一侧；`lanes`=1 退化为全宽随机。破裂的放大放在**内层 svg** 而不是定位按钮上：按钮靠 `transform:translate`

  「此刻」两行**不走数值快照那条通道**：快照一分钟才推一把，而这两行要一秒一跳
  （`ONLINE_TICK_MS`，且必须挂定时器不能挂 rAF——这扇窗没焦点，rAF 会被节流，见 §5.25）。
  在线时间 = **本次进程启动了多久**（主进程记 `startedAt` 随快照推过来，不入库），
  和存档里的 `lastSeenAt`（上次见到你是多久前，开口台词读它）是两回事——混用会把
  「关机八小时」显示成「在线八小时」。
- **存档 v2**：`version: 2`，新增 `identity{name,gender}` 与四条数值。v1 的 `stats` 是占位形状
  （`{hunger,mind,clean,mood}` 全 80，且没有任何生产调用方改过它），迁移时 hunger/mood 沿用、
  mind/clean 丢弃。坏档一律回退默认值并记 `warnings`，永不抛异常。
- **光标**：交互区内是同一枚 Kenney `hand_point`（CC0，热点 (9,2) 是指尖，按 PNG 的 alpha 实测量出来的），
  值只有 CSS 变量 `--pet-cursor` 一份。**交互区 = 身体框、开着的面板、开着的气泡三者的外接矩形**——
  取外接矩形而不是并集，是为了**连续**：身体到面板之间那截、按钮之间那 8px、面板与气泡之间那 12px，
  按各自矩形判都会落空，手形会一路闪回桌面的样子。都收起后区域缩回只剩身体。
  代价说清楚：面板开着时那截看不见的空隙，点击归我们（按下不反应）。但"算不算有人在使用"
  仍然只问 DOM 命中——停在空隙里不算活动，1500ms 收起照旧跑，所以吞点击的时间有上界。
  qqpet 把光标挂在 `html,body` 上（它的窗就只有宠物那么大，整窗等于交互区），
  我们是整屏穿透窗，只能跟着区域开关。
- **自主行为**：没人理它超过 20 秒，它开始按皮肤 `weights` 自己在待机 / 转身之间抽。
  平行走动（`move`）暂时不在自主池里——这版形象更适合待在原地做小动作，想放回来把
  `AMBIENT_POOLS` 里的 `'move'` 加回去就行，走动那套素材和皮肤契约都没动。
- **托盘菜单**（2026-11-12 取代面板里的设置页）：右键托盘图标，菜单依次是：
  - **显示桌宠 / 隐藏桌宠**：会话命令，不写存档，新进程一律可见；双击托盘图标＝显示。
    「隐藏」会压住全屏探测的下一拍，用户不点「显示」就不会被自动放出来。
  - **静音**（默认关）：勾上关掉**整个项目**的语音（台词配音）。
  - **全屏时隐藏**（默认关）：放映/演示模式与独占/无边框全屏**统称全屏**，共用这一挡。
    判据是 Windows 的通知状态（state=4 认演示/放映，state=2/3 认独占全屏）加上「前台窗口是否铺满整块屏」，
    后者带一张系统外壳排除表，否则锁屏界面会被当成有人在全屏。
  - **开发者模式**（默认关）：勾上才显示动作按钮条里的「调试」那颗。
  - **皮肤**：列出内置 `skins/` 与用户目录 `%APPDATA%\with-me\skins\` 下所有带 `manifest.json` 的皮肤，
    当前皮肤打勾；点另一项会写进存档并自动重启（皮肤在启动时装载，热换不稳）。
    大肥鱼皮肤包是独立下载的 CC BY-NC-SA 4.0 资源包，不进主程序；
    托盘的「皮肤 → 导入皮肤包…」可以直接选 zip 导入：先校验包结构，再把包内许可摊给用户确认，
    通过后解压到用户皮肤目录、写存档并重启。
  - **退出**：先亮出宠物，再随机播一条收尾动画 + 一句再见（带语音），等两者都演完再落盘退出（12 秒兜底强退）。
  勾选类设置改了立刻写进 `save.json` 的 `settings`，不用退出（`developerMode`/`muted` 是布尔，旧档自动补默认值；
  旧档里的 `onPresentation` 已并入 `onFullscreen`，装载时直接忽略）。
- **台词语音**：200 句台词各配一条 mp3（`src/renderer/voice/line-NNN.mp3` + `manifest.json` 的 text→file 映射，
  BreezeBlue TTS 生成）。弹气泡时按台词原文查表播对应语音（`renderer/audio.ts`）。气泡停留靠语音真实事件驱动——
  播放期间用 `timeupdate` 一路续期，语音 `ended` 后再多停 1 秒（`VOICE_BUBBLE_PAD_MS`）才收；
  不靠 `duration` 数字（本地 mp3 可能报 0/Infinity，算少就提前收）。静音 / 查无此句 / 出错回落到默认 5 秒。
- **启动 / 退出动画**：开机问候随机播一条启动片（舞狮头 / 女仆舞 / 摇摆舞 / 动物环绕 / 小幽灵 / 堆雪人 / 荡秋千 / 放风筝，
  `STARTUP_CLIPS`）+ 一句随机问候语音；退出随机播一条收尾片（被落叶淹没 / 女仆屈膝礼仪 / 超大伸懒腰 / 清点归档，
  `EXIT_CLIPS`）+ 一句再见语音，**等动画和语音都演完才退**（行为链演完标记 + 音频 `ended`，两边都齐才 `quitApp`，
  另有 10 秒兜底防卡死）。皮肤没有这些具名片（如占位 block 皮肤）就回落 `click` 池，保证有动作收尾。
- **命中区可视化**：`Ctrl+Shift+点身体` 画出红色身体框，再点一次消失。排查
  「鼠标停在身上没反应」这类问题用得上。（不用 F9：这扇窗故意不可聚焦，收不到键盘事件）

存档在 `%APPDATA%\with-me\save.json`，每次退出时写。用户自己放的皮肤放
`%APPDATA%\with-me\skins\`，同名时优先于内置。

## 怎么自定义皮肤

一个皮肤 = 一个目录，里面一份 `manifest.json` 加若干带透明通道的 webm。
完整契约见 [`docs/superpowers/specs/2026-11-02-skin-pack-contract.md`](docs/superpowers/specs/2026-11-02-skin-pack-contract.md)，
这里是速查版。

```
skins/<皮肤id>/
  manifest.json
  animation/
    idle/    patrol.webm  patrol2.webm
    turn/    left.webm
    move/    step.webm
    click/   tapped.webm
    drag/    pulled.webm
```

动画文件的地址由**池名和文件名**拼出来：`animation/<池>/<名字>.webm`。
名字就是文件名（不含后缀），不是数组下标。

### manifest 最小可用版

```jsonc
{
  "formatVersion": 1,
  "name": "我的宠物",
  "canvas": { "w": 640, "h": 360, "feetY": 330 },
  "bodyBox": { "x": 200, "y": 50, "w": 240, "h": 285 },
  // 可选：看得见的身子（墨迹范围）。命中框是拿来点的，作者会刻意留宽一点，
  // 所以两者不是一回事：色块实测墨迹比 bodyBox 左右各窄 10px，dshtry 那只鲸鱼各窄 37px。
  // 省略时按 bodyBox 处理（内缩 0）。目前只有飘字用它摆位置。
  "inkBox": { "x": 220, "y": 58, "w": 199, "h": 269 },
  "pools": {
    "idle":  ["patrol", "patrol2"],
    "turn":  ["left"],
    "move":  ["step"],
    "click": ["tapped"],
    "drag":  ["pulled"]
  }
}
```

| 字段 | 必填 | 规则 |
|---|---|---|
| `formatVersion` | 是 | 只能是 `1`。不认识就拒绝装载并提示升级程序，不猜 |
| `name` | 是 | 展示用 |
| `canvas` | 是 | 必须 `640×360`；`feetY` 在 1–359 之间 |
| `bodyBox` | 是 | 身体占的画布矩形，命中判定和贴边的依据，必须完整落在画布内 |
| `pools` | 是 | 五个必需池 `idle/turn/move/click/drag` 一个都不能少，每池至少一条 |
| `weights` | 否 | 池级权重，只影响自主走动选哪个池；不写等于全 1 |
| `animationMeta` | 否 | 单条动画的 `loop` / `mirrorable` / `bodyBox` 覆盖 |
| `hotspots` | 否 | v2 互动用，v1 只透传 |

池名与动画名只允许 `[a-z][a-z0-9_-]`（池名 ≤32、动画名 ≤40）。它们要当文件名用，
也要拼进 URL，中文和大小写混用在 Windows 上都有坑。

### 三条素材合同

1. **动画周期必须整除素材时长。** 每段动画从标准正面姿势起步、末尾回到这个姿势，
   这样任何一段播完都能无缝接回待机。**不要把首帧复制一份当末帧**，那会多停一帧。
   周期取 1.6 秒这种不整除 4 秒的值是最常见的错法：末帧停在半空，每次接缝就跳一下。
2. **角色任何一帧都不许出 `bodyBox`。** 出框的后果是命中判定错位——鼠标停在
   看得见的身上不弹面板，停在看不见的框里反而弹。原地动作（呼吸、摆尾、跳跃）写在
   动画里；**位移（走路、跑动）不写在动画里**，由程序移动整个舞台实现。
   轮廓剧变的动作（趴下、缩成一团）要在 `animationMeta.<名>.bodyBox` 里单独给框。
3. **编码必须是 VP9 + alpha 的 WebM：**

   ```bash
   ffmpeg -y -i 输入.mov -vf "colorkey=0x0000FF:0.30:0.05,format=yuva420p" \
     -c:v libvpx-vp9 -pix_fmt yuva420p -crf 8 -b:v 0 -auto-alt-ref 0 -row-mt 1 -an 输出.webm
   ```

   不显式写 `-c:v libvpx-vp9` 会**静默丢掉 alpha 通道**——画面看着正常，背景变成
   一整块不透明矩形。`-auto-alt-ref 0` 也不能省。

### 交付前必做

```bash
npm run alpha:check skins/mine/animation/idle/patrol.webm
# 期望：{"frames":8,...,"bgAlphaMax":0,"haze":false}
```

`haze:true` 说明背景没抠干净，或者角色跑出了 `bodyBox`。这个工具分不清这两种，
两种都要排查。调小 `colorkey` 的相似度容差（第二个数，0.30 → 0.20）重导。

## 已知限制

- **运行中改显示器会跟随，但只跟主屏**：`display-metrics-changed / display-added / display-removed`
  三个事件都会触发一次 `refit`（`src/main/index.ts`）——重读主屏 `workArea`，同时
  ① `platform.setOverlayBounds` 重摆覆盖层（带守卫，尺寸没真变就不动，避免这个品类最怕的改尺寸抖动），
  ② 换掉系统光标原点，③ 渲染层收到 `window resize` 后 `motion.setBounds` 重算夹取并把宠物夹回可见区。
  所以改分辨率 / 系统缩放 / 旋转 / 任务栏自动隐藏 / 显示器插拔都不必再重启。
  **仍不处理的**：把宠物"搬"到另一块屏（它永远在启动时那块，多屏拓扑大改仍以重启为万能兜底），
  以及宠物本身固定 320×180、不随屏大小缩放（观感，不是故障）。
- **没有 CSP**：页面目前只加载本地 `app://` 资源、DOM 全部走 `textContent`，没有直接注入点，
  所以这不是当下可利用的漏洞；但等加入富文本或第三方皮肤元数据时就该补上（复审 #3 P2）。

## 常见故障

| 现象 | 原因与处理 |
|---|---|
| 宠物周围有一块灰色/蓝色矩形底 | 素材 alpha 没做好。跑 `npm run alpha:check`；确认编码命令里有 `-c:v libvpx-vp9` 和 `-pix_fmt yuva420p` |
| 鼠标停在宠物身上没反应 | `Ctrl+Shift+点身体` 看红框和看得见的轮廓对不对得上。对不上就是 `bodyBox` 写小了，或者动画把角色画出了框 |
| 面板弹出来但点不动按钮 | 穿透租约被放开了。看主进程控制台有没有 `[fullscreen]` 或 IPC 报错；确认渲染层心跳还在发（`window.__petDebug.grabSends` 应该持续增长） |
| 整块屏幕点不动 | 兜底机制会在 500 毫秒后自动恢复穿透。如果持续发生，说明渲染层在反复请求接住鼠标，检查交互区判定 |
| 全屏看视频/玩游戏时被宠物盖住 | 让路探测没起来。检查 `powershell.exe` 是否被安全策略拦住，主进程控制台会有 `[fullscreen]` 错误 |
| 换皮肤没生效 | 看控制台有没有「找不到皮肤」警告。用户皮肤要放在 `%APPDATA%\with-me\skins\<id>\`，且 `save.json` 的 `skin` 字段要等于目录名（小写字母数字下划线短横线） |
| 动画接缝处跳一下 | 素材周期没整除时长，见上面第 1 条合同 |
| 启动后什么都没有 | 打开 DevTools 看控制台。皮肤装载失败时屏幕上会出现红色错误框；如果连错误框都没有，检查 `dist/preload/index.cjs` 是否存在 |

## 发布流程

日常开发不需要这些命令，只有出包时才跑。产物一律落在 `release/`（不进 git；`dist/` 是 tsc 的地盘，别让给打包）。

| 想做 | 命令 | 出什么 |
|---|---|---|
| 出主程序包 | `npm run dist` | `with-me-<版本>-setup.exe` + `with-me-<版本>-portable.zip` |
| 验装机产物 | `node e2e/package-check.mjs` | 页面 / 动画 / 语音 / 字体是不是真从包里取到了 |
| 查素材许可 | `npm run check:license` | 没登记的、形象素材混进来的，逐条报错并退码 1 |
| 装大肥鱼包 | `npm run skin:pack` | `with-me-skin-dafeiyu-<版本>.zip`（素材不进 git，只能本地出） |

### 发一版

1. 全门禁：`npm run typecheck && npm test && npm run build && npm run e2e && npm run check:license`
2. 出包自检：`npm run dist && node e2e/package-check.mjs && npm run skin:pack`
3. **仓库得是 Public**，否则 Release 下载页要登录才打得开——目标是不登录就能下。
4. 推 tag：`git tag v<版本> && git push origin v<版本>`，CI 自动出包并建 Release。
5. 补挂皮肤包（素材不在 git，CI 拿不到，这一步只能手工）：
   `gh release upload v<版本> release/with-me-skin-dafeiyu-<版本>.zip`
6. 用没登录的浏览器开一次 Release 页，三个文件都下得动，才算发完。

版本号只改 `package.json` 的 `version`，tag 与它对齐。
`e2e` 不进 CI：它要真机窗口和 Win32 z 序读数，runner 上的结果不可信。

### v1 明确没有的两件事

- **代码签名**：没证书。Windows SmartScreen 会弹「未知发布者」，这是预期，不是坏了。
- **自动更新**：不检查新版也不下载，要更新就自己回 Release 页拿。

一句话架构：Electron 双进程 + 一个共享纯逻辑层。主进程只做建窗、穿透开关、光标推进、
焦点切换四件事（全部收在 `Platform` 接口后面），皮肤校验、命中判定、面板收起计时、
行为调度、播放器抽象全是不依赖 Electron 和 DOM 的纯函数，所以能被单测覆盖。
素材走自定义协议 `app://`，因为 Chromium 禁止 `file://` 页面 import ES 模块。

## 已验证的关键事实

- 整屏透明覆盖层 + **保留硬件加速**在真机成立：宠物框外 580 万像素不透明数为 0，
  真实屏幕差分意外变化为 0，24fps 不掉帧，CPU 稳态 1.4%。
- **不能用 `<video loop>`**：实测每次循环回到起点都要重新缓冲。重复播放由行为层
  再调一次 `play()` 实现。
- 主进程 ESM 入口不能写顶层 `await`，会与 `app.whenReady()` 互等死锁。
- `ipcMain.on` 必须早于 `loadFile`，否则渲染层首帧消息静默丢失。

详细数据见 `spike/README.md`。
