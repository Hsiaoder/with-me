# with-me · Windows 桌面宠物

一只站在桌面上的宠物。它自己按规则播动画，点一下出按钮面板，其余区域的鼠标完全穿过它——
该点点桌面、该拖拖窗口，不受影响。换一只宠物 = 换一个皮肤目录。

## 安装

Windows 10 / 11（x64）。在 [Releases](https://github.com/FionnHsiao/with-me/releases) 里挑一个：

### 免安装版（推荐）

1. 下载 `with-me-<版本>-portable.zip`，解压到任意目录；
2. 双击 `with-me.exe`。

### 安装版

下载 `with-me-<版本>-setup.exe`，运行后选安装目录。

> 程序未做代码签名，Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
> 如果 Windows 11 开着**智能应用控制**（Smart App Control），未签名 exe 会被直接拦截、无法放行；
> 这种情况请用下面的源码包。

### 源码包（免签名渠道）

1. 安装 [Node.js](https://nodejs.org/zh-cn) 22 或更高；
2. 下载 `with-me-<版本>-source.zip` 并解压；
3. 双击 `run.cmd`。首次会下载 Electron 运行时（约 350 MB，只需一次），
   之后日常双击 `启动.vbs` 即可，不弹控制台窗口。

### 卸载与重置

- 免安装版 / 安装版：存档在 `%APPDATA%\with-me\`，删掉即恢复出厂；删掉程序目录即卸载。
- 源码包：存档在包内 `userdata\`，删掉同样恢复出厂。
- 不写注册表，也没有开机自启。

## 功能

### 桌面行为

- 整屏透明覆盖层，宠物以外的区域鼠标完全穿透，桌面照常操作。
- 拖动宠物换位置；点一下出按钮面板，再点收起。
- 视频、游戏全屏时自动隐藏（托盘里可以关掉这个行为）。
- 只显示在主屏；改分辨率、缩放、任务栏设置都不用重启。

### 互动

点宠物弹出按钮面板（默认三个，「调试」只在开发者模式下出现）：

- **喂食**：16 种食物，开局解锁 4 种，其余按等级解锁；影响饥饿、心情、体重和经验，吃完才说话。
- **小游戏**：鲸鲸会飞、猜动作、点泡泡。
- **状态**：饥饿、心情、体重、亲密度，以及等级和本次在线时间。
- **调试**：切换动画、翻台词表、拉数值滑条。

### 说话与语音

- 闲久了会自己搭话；喂食和点按钮必定回应一句。
- 每句台词都有配音（200 条 mp3），可以在托盘里静音。
- 有音乐在播时会跟着哼歌 / 摇摆，并且只弹气泡不出声，不跟你的歌叠音。

### 养成

- 四条数值：饥饿、心情、体重、亲密度。关闭宠物期间冻结，在线时缓慢变化。
- 喂食与互动积累经验升级，逐步解锁食物。
- 每天第一次打开加一点亲密度。

### 皮肤

- 内置「色块」占位皮肤，开箱即用。
- 托盘菜单 → 皮肤 → 导入皮肤包…，选 zip 即可换角色，导入后宠物会重启。
- 大肥鱼皮肤在同一个 Release 里单独下载（CC BY-NC-SA 4.0，禁止商用）；
  源码包用户把 zip 原样丢进 `skins-inbox\` 后重启，会自动装好。

## 托盘

右键托盘图标：显示桌宠 / 隐藏桌宠、静音、全屏时隐藏、开发者模式、皮肤、导入皮肤包…、退出。
双击托盘图标 = 显示桌宠。
